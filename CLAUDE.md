# Changelog

`CHANGELOG.md` is this project's change history (there is no git). At the
start of a session, read it to see what has changed. After making any change
— or when the user describes a change they made themselves — add an entry
under today's date (`## YYYY-MM-DD`, newest first) in the right group
(Added / Changed / Fixed / Removed), naming the main files touched.
